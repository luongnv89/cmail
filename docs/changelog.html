Release history

Changelog

The highlights of each release. Full details are in CHANGELOG.md.

v0.3.0

11 October 2026 · release

  • NewInstall with one command, no clone: curl -fsSL https://raw.githubusercontent.com/luongnv89/cmail/main/install.sh | bash. The installer says whether ~/.local/bin is on your PATH and prints the line to add if not.
  • ChangedPlain bash install.sh now installs the v0.2.0 runtime instead of v0.1.0. The cmail commands did not change in this release, so cmail --version still prints cmail 0.2.0 after a one-line install.
  • FixedThe installer no longer fails when piped from curl, and does nothing if the download is interrupted.
  • DocsWebsite rewritten: an 8-step visual setup guide with a progress tracker and a walkthrough of a real cmail setup session, plus new Docs, Changelog and Privacy pages.
  • DocsSetup guide: adding your domain to Cloudflare now comes before cmail setup, with a link to Cloudflare’s instructions, and is only needed if the domain is not on Cloudflare yet. Ticking all 8 steps shows a congratulations card.
  • Action neededProgress from the old 14-step checklist is not carried over. Tick your finished steps again in the new 8-step guide.

v0.2.0

10 October 2026 · release

Any registrar, no GoDaddy needed

  • ChangedSetup defaults to REGISTRAR=manual: bring a domain from any registrar. cmail prints the nameservers and waits for activation. GoDaddy automation is now opt-in with --registrar godaddy.

A new, safer CLI

  • Newcmail list: every address on a domain and where it forwards.
  • Newsetup --dry-run previews the whole workflow without changing anything.
  • Newcmail config commands, secret input via --stdin, JSON output, shell completions.
  • NewSetup reports the elapsed time on success or failure.
  • ChangedReceiving needs no Google account. Gmail sending moved to the optional cmail send-as.
  • ChangedAny purchase needs the domain typed at a terminal; flags or piped input can never approve one.
  • Fixedcmail status no longer fails on rules without a forward destination.

Also

  • NewUser-local installer, the cmail-setup agent skill, this website, and macOS/Linux CI.

v0.1.0

7 October 2026 · release

  • NewFirst release. cmail setup automates GoDaddy, the Cloudflare zone, nameservers, Email Routing, destination verification and forwarding rules, then guides Gmail “Send mail as”.
  • Newcmail status and cmail doctor.
  • FixedReliable nameserver comparison, rule and destination reuse, account selection and recovery messages.
