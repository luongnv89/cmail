Custom-domain email in three simple steps.

1. Install

From the reviewed source, run bash install.sh. Bring a GoDaddy domain and a free Cloudflare account.

2. Run cmail setup

Approve GoDaddy in your browser, paste a scoped Cloudflare token, confirm the nameserver switch and click one verification email. cmail creates the forwarding for you.

3. Send yourself a test

From another mailbox, write to hello@your-domain and see it arrive in your inbox. That’s it: receiving is set up.

Sending is optional, not the default. Only if you also want to send as hello@your-domain, run cmail send-as afterwards. It guides Gmail “Send mail as” and needs a Gmail/Google account. Receiving never needs it.

Know the boundaries.

Do I need Gmail or a Google account?

Not to receive. cmail setup forwards to any address you own and can open. You need a Gmail/Google account only for the optional cmail send-as step, if you want to send from your custom address.

Does cmail provide a mailbox?

No. Cloudflare forwards incoming mail to an existing inbox. Your existing inbox holds the messages. This is not Google Workspace provisioning.

Is everything automatic?

No. You create the Cloudflare token, approve DNS changes, verify the destination email, and, only if you want to send, configure Gmail send-as yourself. The CLI cannot prove end-to-end delivery.

What does it cost?

You pay for the domain. Provider plans, sending limits, eligibility and policies still apply; cmail cannot guarantee permanent free service.

Can I preview setup safely?

The guide makes no provider calls. cmail help is offline. DRY_RUN=1 previews only nameserver replacement; cmail setup can still create zones, enable routing, send verification emails or purchase a domain.

Will this guarantee professional deliverability?

No. Optional Gmail sending does not establish domain DKIM alignment, and recipients may see your Gmail address. Inspect independent test results and use a dedicated mail service when you need stronger guarantees.

Is the agent skill certified or installed automatically?

No. It is a separate portable guide and optional local checker. Its offline tests are not a measured live behavioral benchmark. The runtime installer does not install it; the repository has no license granting redistribution rights.
