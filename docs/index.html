Four steps from domain to inbox.

  1. 1

    Install

    Run one curl command. No clone, no sudo.

  2. 2

    Create a token

    One scoped Cloudflare API token. Setup opens the page for you.

  3. 3

    Run cmail setup

    Answer two questions. cmail creates the zone, routing and rules.

  4. 4

    Test

    Email your new address from another mailbox and watch it arrive.

DNS propagation can add waiting time. cmail waits for you and can be rerun at any point; finished steps are skipped.

Quick answers.

Does cmail give me a new mailbox?

No. Cloudflare forwards incoming mail to an inbox you already own. That inbox stores the messages.

Can I send from my custom address?

Sending is optional. cmail send-as walks you through Gmail “Send mail as”. Google has announced it will remove third-party “Send as” starting January 2027, so check Google’s help page before relying on it.

What does it cost?

You pay for the domain. Cloudflare Email Routing is free; provider plans and limits still apply.

Will it break my website or existing email?

Only if you skip a step. Before switching nameservers, copy your existing DNS records into Cloudflare. The guide shows exactly when.

Does cmail collect any data?

No. It talks only to Cloudflare (and GoDaddy if you opt in) with your own token. See Privacy.
